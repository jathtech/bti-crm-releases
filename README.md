## Behavioral Style Snapshot

A mobile-friendly, forced-ranking (ipsative) behavioral-style self-assessment: 10 screens of four words each, ranked 4 → 1 by drag or tap, scored into four dimensions (D, I, S, C) that always total 100.

- App: [`style-snapshot/index.html`](style-snapshot/index.html) — a single self-contained page, no build step or backend.
- Live copy: <https://claude.ai/artifact/KuwfSYrKBGfCD6btFoi5oj> (QR: [`style-snapshot/qr/qr-claude-artifact.png`](style-snapshot/qr/qr-claude-artifact.png))
- To host it from this repo instead, enable GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`). It will then be served at <https://jathtech.github.io/bti-crm-releases/style-snapshot/> (QR: [`style-snapshot/qr/qr-github-pages.png`](style-snapshot/qr/qr-github-pages.png)). The page's own Share panel already points at that address.

This is an independent four-dimension assessment based on William Moulton Marston's public-domain four-factor model. It is not an official or certified DiSC® product and is not affiliated with John Wiley & Sons.
